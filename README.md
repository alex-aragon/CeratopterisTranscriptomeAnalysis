# Transcriptome Analysis performed in the paper "Transcriptional analysis of Ceratopteris richardii young sporophyte reveals conservation of stem cell factors in the root apical meristem"
Repository contains all scripts for each step and/or software used to analyze the generated dataset from the paper "Transcriptional analysis of Ceratopteris richardii young sporophyte reveals conservation of stem cell factors in the root apical meristem" (2022) published in Frontiers in Plant Science (https://doi.org/10.3389/fpls.2022.924660)
 
Scripts were run either in bash or R. All different softwares and packages listed in each script and used in this analysis were selected based on literature and comparing outcomes with similar tools.
